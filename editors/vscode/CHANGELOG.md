# Changelog

## 2.1.0

- Added highlighting for `async`, `await`, `import`, and `export`.
- Updated the built-in function list with networking, promise, module, null-safe, text, and collection helpers.
- Added snippets for async functions, imports, exports, and HTTP requests.
- Works with the 2.1 CLI, async execution, modules, and the browser Studio.

## 2.0.0

- Initial release.
- Syntax highlighting, indentation rules, folding, and snippets for AzLang.
- Run File and Run Selection commands using the installed `azlang` command.
- Open AzLang Studio and documentation commands.
- Status bar Run action for `.az` files.
- Works in VS Code 1.75 and newer, Cursor, Windsurf, and VSCodium.
