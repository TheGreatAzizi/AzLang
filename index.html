Why AzLang

Small enough to learn.
Powerful enough to keep.

Most beginner languages either hide the interesting parts or drown you in punctuation. AzLang takes the middle path: a tiny, readable syntax with the ideas that actually matter.

Learnable in an afternoon

One keyword per idea. Blocks open with a keyword and close with end. No semicolons, no braces, no noise.

if score >= 90 say "Excellent!" end

Modern where it counts

Classes and inheritance, closures, default parameters, arrow lambdas, destructuring loops, and pattern matching.

let double = x => x * 2 map([1, 2, 3], double)

Batteries included

Strings, lists, maps, math, sorting, higher-order helpers, random numbers, and JSON — all built in.

filter(nums, n => n % 2 == 0) json_encode({name: "Ada"})

Errors that teach

Plain-English messages with line numbers, a useful hint, and “did you mean?” suggestions for typos.

# Instead of a stack trace:
Variable "cuont" is not defined
Hint: Did you mean "count"?

Speaks your language

Full Unicode support: Persian text, identifiers, and digits work naturally alongside English.

let شهر = "تهران" say "{شهر} — {۱۲ + ۳}"

Runs anywhere, instantly

One file, zero dependencies. Run programs in Node, use the interactive shell, or code in the browser IDE.

$ node azlang.js hello.az $ node azlang.js # REPL

# Numbers with a purpose
let numbers = range(1, 11)

let squares = map(numbers, n => n * n)
let evens = filter(numbers, n => n % 2 == 0)
let total = reduce(numbers, (a, b) => a + b)

say squares
say evens
say "Sum: {total}"

# [1, 4, 9, 16, 25, 36, 49, 64, 81, 100]

Functional style

Lambdas and higher-order helpers let you say what you mean, not how to loop.

  • Arrow lambdas: x => x * 2
  • map, filter, reduce, any, all
  • Destructuring: for i, v in enumerate(list)
  • Strings interpolate any expression

Kind by design

Mistakes are part of learning. The messages should help.

AzLang never answers a typo with a cryptic stack trace. Every error tells you what happened, where it happened, and what to try next.

  • Clear messages in plain English
  • Exact line numbers, shown in the editor
  • Hints and close-name suggestions
  • Catchable errors with try / catch
